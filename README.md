# One Word, First Thought

> apophenia

The one word that came to mind: apophenia, the tendency to see meaningful
patterns in random noise. Faces in clouds, messages in static, a shape in
the wallpaper that looks back at you. It is a psychology term, not a word
from the usual beautiful-word lists, so it is the kind of word a reader
would not have guessed. It calls up a clear image because almost everyone
has caught themselves doing it. And it carries a small joke: a technical
word for inventing meaning where there may be none, doing exactly what
it names.

## Run

```sh
python3 main.py
```

Writes exactly one word, `apophenia`, to `/output/entry.txt`, with no
trailing newline. The program validates the word against the bounty gate
first: 1 to 24 characters, UTF-8, not only white space, exactly one word.
